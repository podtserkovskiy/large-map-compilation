# Large Map Compilation Error Repro

## Regular map literal
Demonstrates the use of a normal map literal.
```sh
$ go build -gcflags='-N -l' ./literals #fails
```
Error message:
```
# example.com/hello/literals
<autogenerated>:1: internal compiler error: NewBulk too big: nbit=35669 count=612136 nword=1115 size=682531640
```

## Anon function initializer workaround
Instead of using a large map literal directly, we define an anonymous function that populates the map with data and call it immediately.

Example of workaround func:
```go
var largeMap = func() map[string]int {
    m := make(map[string]int)
    // populate m with many entries
    m["key1"] = 1
    m["key2"] = 2
    // ...
    return m
}()
```

This works, but it would be preferable to avoid needing this workaround.
```sh
$ go build -gcflags='-N -l' ./workaround # succeeds
```
